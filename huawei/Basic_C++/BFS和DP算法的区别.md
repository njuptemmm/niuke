# BFS 和 DP 算法的区别（以最少硬币数为例）

下面这张表按“同一题（最少硬币数）”对比 BFS 和 DP：

| 对比维度 | BFS 视角 | DP 视角 | 本题表现 |
|---|---|---|---|
| 问题抽象 | 图最短路（无权图） | 最优化状态转移 | 都在求“金额 i 的最少硬币数” |
| 状态含义 | `dist[i]`：到金额 `i` 的最少步数 | `dp[i]`：凑出 `i` 的最少硬币数 | 语义一致 |
| 初始状态 | 起点入队（`0` 或所有 `coin`） | 设基准值（`dp[0]=0` 或 `dp[coin]=1`） | 你用了“coin 作为第一层/初始可达” |
| 状态转移 | `i -> i+coin`（走一条边） | `dp[i] = min(dp[i], dp[i-coin]+1)` | 本质是同一条边的正反写法 |
| 遍历顺序 | 按层扩展（队列） | 按金额顺序递推（双循环） | 一个是“层序”，一个是“枚举取最小” |
| 最优性来源 | 第一次到达即最短（无权图性质） | 枚举所有来源后取最小值 | 都能保证最优 |
| 去重/剪枝 | `visited` 或 `dist==-1` 防重复入队 | `INF` 表示不可达，仅可达状态转移 | 都在防无效扩散 |
| 是否可提前结束 | 可以（弹出 `amount` 时可停） | 通常不行，要算到 `amount` | BFS 可能更早停 |
| 复杂度（本题常见） | 时间 `O(amount*n)`，空间 `O(amount)` | 时间 `O(amount*n)`，空间 `O(amount)` | 量级接近 |
| 更通用到哪类题 | 最少步数、最短路径、显式图搜索 | 计数/最值/可行性、子问题明显 | 这题两种都自然 |

## 为什么你会感觉两者“几乎一样”

1. 这题每次操作代价都等于 `1`，天然可建模为无权最短路。
2. 同时它也满足标准递推关系，天然可写成 DP。
3. 两者都在同一个状态图上做最优值计算，只是“求值流程”不同。

## 实战速判口诀

1. 看到“最少操作次数 + 每步代价相同 + 可以看成走图”，优先想 BFS。
2. 看到“`dp[i]` 明确依赖更小状态 + 公式好写”，优先想 DP。
3. 两者都能做时，选边界更清晰、更不易写错的实现。

## 一句话总结

在这道题里，BFS 和 DP 不是谁替代谁，而是同一个最优化问题的两种等价求解视角：
- BFS：按层找最短步数。
- DP：按状态递推取最小值。

# C++ 位运算总结

## 一、基本位运算符

| 运算符 | 名称 | 示例 | 结果 | 规则 |
|--------|------|------|------|------|
| `&` | 按位与 | `a & b` | - | 同为1时为1 |
| `\|` | 按位或 | `a \| b` | - | 有1则为1 |
| `^` | 按位异或 | `a ^ b` | - | 不同为1，相同为0 |
| `~` | 按位取反 | `~a` | - | 0变1，1变0 |
| `<<` | 左移 | `a << n` | - | 左移n位，低位补0 |
| `>>` | 右移 | `a >> n` | - | 右移n位，高位补符号位 |

示例：
- `10 & 12 = 8` (1010 & 1100 = 1000)
- `10 | 12 = 14` (1010 | 1100 = 1110)
- `10 ^ 12 = 6` (1010 ^ 1100 = 0110)
- `10 << 2 = 40` (1010 → 101000)
- `40 >> 2 = 10` (101000 → 1010)

## 二、位的修改与查询

### 1. 位的设置（置 1）
```cpp
x | (1 << n)        // 将第 n 位置为 1
x |= (1 << n);      // 原地修改
```

### 2. 位的清除（置 0）
```cpp
x & ~(1 << n)       // 将第 n 位置为 0
x &= ~(1 << n);     // 原地修改
```

### 3. 位的翻转
```cpp
x ^ (1 << n)        // 第 n 位翻转（0↔1）
x ^= (1 << n);      // 原地修改
```

### 4. 位的查询
```cpp
(x >> n) & 1        // 获取第 n 位的值（0 或 1）
if (x & (1 << n))   // 判断第 n 位是否为 1
```

### 5. 位的修改
```cpp
x = (x & ~(1 << n)) | (val << n);  // 将第 n 位设为 val（0或1）
```

## 三、常用技巧速查表

| 用途 | 代码 | 说明 |
|------|------|------|
| **判断奇偶** | `x & 1` | 1=奇数, 0=偶数 |
| **交换两数** | `a^=b; b^=a; a^=b;` | 无需临时变量 |
| **取绝对值** | `(x ^ (x >> 31)) - (x >> 31)` | 对int有效 |
| **低n位清零** | `x & (~0 << n)` | 保留高位 |
| **保留低n位** | `x & ((1 << n) - 1)` | 等价于 `x % (1<<n)` |
| **右对齐n个1** | `(1 << n) - 1` | 如 n=3 → 0b111 |
| **2的幂** | `1 << n` | 等价于 2ⁿ |
| **判断2的幂** | `x && !(x & (x - 1))` | 是则返回true |
| **最低位的1** | `x & -x` | 保留最右边的1 |
| **清除最低位的1** | `x & (x - 1)` | Brian Kernighan 算法 |

## 四、实战应用示例

### 示例 1：统计二进制中 1 的个数
```cpp
int count_ones(int x) {
    int cnt = 0;
    while (x) {
        x &= x - 1;  // 清除最低位的 1
        cnt++;
    }
    return cnt;
}
```

### 示例 2：枚举子集
```cpp
// 枚举 mask 的所有非空子集
for (int s = mask; s; s = (s - 1) & mask) {
    // 处理子集 s
}
```

### 示例 3：位标志（Flags）
```cpp
const int FLAG_A = 1 << 0;  // 0b0001
const int FLAG_B = 1 << 1;  // 0b0010
const int FLAG_C = 1 << 2;  // 0b0100

int state = FLAG_A | FLAG_C;        // 设置标志
if (state & FLAG_B) { /* ... */ }   // 检查标志
state &= ~FLAG_A;                   // 清除标志
```

### 示例 4：Gray 码生成
```cpp
int gray_code(int n) {
    return n ^ (n >> 1);
}
```

### 示例 5：生成所有将某一0位修改为1的数值
```cpp
for (int p = 0; p < 20; ++p) {
    if (((x >> p) & 1) == 0) {
        ans.push_back(x | (1 << p));
    }
}
```

## 五、注意事项

| 注意点 | 说明 |
|--------|------|
| **类型安全** | 用 `1L << n` 而非 `1 << n` 避免溢出 |
| **符号位** | `>>` 对有符号数通常是**算术右移**（补符号位） |
| **移位位数** | 移位位数不能 ≥ 类型位数（如 `int` 不能移 ≥32 位） |
| **优先级** | 位运算优先级较低，建议加括号明确意图 |
| `~` 运算符 | `~x` 结果与机器位数有关，注意溢出 |

## 七、十进制与二进制转换

### 使用 bitset
```cpp
#include <bitset>
long int num = 123;
bitset<16> binary(num);           // 十进制 -> 二进制
cout << binary << endl;           // 输出二进制
bitset<16> b("1010101");     // 从字符串构造
long int n = b.to_ulong();       // 二进制 -> 十进制
```

### 手动实现
```cpp
// 十进制 -> 二进制字符串
string dec_to_bin(long int num) {
    if (num == 0) return "0";
    string s;
    while (num > 0) {
        s += (num & 1) ? '1' : '0';
        num >>= 1;
    }
    reverse(s.begin(), s.end());
    return s;
}
```

## 八、复合赋值运算符

| 运算符 | 等价于 | 作用 |
|--------|--------|------|
| `x |= y` | `x = x \| y` | 按位或后赋值 |
| `x &= y` | `x = x & y` | 按位与后赋值 |
| `x ^= y` | `x = x ^ y` | 按位异或后赋值 |
| `x <<= n` | `x = x << n` | 左移后赋值 |
| `x >>= n` | `x = x >> n` | 右移后赋值 |

### 递归
- 主要就是有一个递归的函数，在这个函数运行的时候同时也要调用这个函数

- 题型思路
    - 注意结束的情况是什么样子的。
        - 结束时候的参数状态（i，j）值的情况。也就是到了什么情况的时候可以说明递归已经结束了
        - 一般来讲我们结束的情况要求的是一个方法，于是说我们是需要一个**path数组来存储一路上的选择的数据**+**一个ans数据用来在结束的时候存储这个path数组**
    - 当一个状态有多个选择的时候：
        - 在当前状态使用push和pop用来遍历在该状态下所有的选择
    - 一般递归的func参数会比较多，建议在使用vector的时候使用&
        - 从含义上来说，带有&是将这个数组拷贝过去，不带是复制一份这个数组过去
        - 从我们实际运用来看这二者是一样的，于是说写代码还是要加上&

### 双指针
- 主要特征是给你一个线性的序列，然后让你寻找在这个序列中满足条件的最小子串/全部字串的数量；其中双指针指的就是我们在解答的时候使用的left和right指针
- 解题思路
    - 最小子串/最长子串
        - 一般是不重复最小子串这样的形式。可以使用一个last[26]/last[10]的表格来存储以字母/数字最后存在的位置，这个是有助于你完成left指针的移动的（一般就是移动到last之后的位置）
        - 使用hash表还真不如直接使用last进行处理
    - 全部子串的数量
        - 难点就是在于要保证你讨论完成的子串是对应所有的子串的。一般来讲是left和right指针中的部分满足什么条件之后剩下的部分也满足这样的条件。

### bfs
- 整体的体验来书相较于使用dfs来说，使用bfs的算法更加容易使用编译来判断问题是否出现问题
- 主要思路就是将初始状态存在队列中，之后不管push出来并且判断这个状态的下一个状态是不是合法的（一个是题目的限制，一个是之前有没有访问过），是合法的就加入到队列中。当队列遍历完成的时候，也就是说明我们考虑完成了所有的情况。其中队列q中存储的情况会使用各种数据结构来简化操作这个要注意
- **vsdfs** 在面对图相关问题的时候，回来防止出现循环，dfs的解决方法是递归的时候增加一个形参parent，避免回环；bfs的思路是有一个visited的数组，来确认不会重复进行访问。
- 其中有一个特别不错的题目是P14047出现了两个限制条件
    - 首先是判断是不是其中一个参数是二分参数（B）。就是那种符合二分算法解答的参数，即值大于一个目标值之后就一直实现。将选择一个满足条件A和条件B的策略->当条件B的情况是B’的时候，此时能不能满足条件A？就可以按照这个的基础完成对于数据的处理

### dfs
- 使用dfs的时候首先需要确定的是：你这个节点需要讨论的数据需要以什么样子进行存储。正常我们问题中每一个节点都是都是一个value，但是在红黑树中我们要存储{hasRED,hasBlack}，在树的遍历中我们存储的节点的是struc node
- 一般是使用对应的二维数组（当然这个会根据不同题目出现变化）存储不同节点之间的关系。为防止出现两个节点之间不断回环，于是我们解决的方法是在使用dfs的时候会传入参数parent来控制
- 一般来讲我们递归的方法是sdjList（存储关系），visit（存储是否访问），path（当前链路的访问路径），node（当前节点），parent（节点的父节点）
- 对于每一个节点的计算：符合条件之后先加入各种函数中之后运行dfs之后再退出所有的函数。

## dp
- 其中涉及到的函数思想是01背包和完全背包这两种不同的思想；
    - 其经典形式是dp[i][j]表示从1~i的数据中，和/结果为j的情况是怎样的
    -前面有共同部分dp[i-1][j]
    -后面是不同的处理方法
        - 01背包：后面部分我们使用的是dp[i][j-i];
            - 其中前面部分是i说明就是我们可以重复使用第i个数字，使用j-i就可以综合之前所有使用i的信息
        - 完全背包：后面部分我们使用的dp[i-1][j-i];
            -  我们是找到除了这个i以外的数据，于是我们使用的是i-1；然后总数再转化成j-i来实现
- 、求解一个满足一个性质子序列的性质
    - 这种题目需要存储当前值是以什么进行结尾的，以及当前值的价格是什么
    - 之前在华为相关的题库中有看到这样的操作

## 并查集
- 算法实现细节
    - 首先就是使用并查集中我们需要使用到的func：find()和merge()；建议是统一使用最原始的形式，方便于后面我们的统一调用。
    -  初始化的时候要使用要将parent[i]=i
        - 在 main 里用 reserve，只是预留容量，不会把元素数量真正变出来。也就是说，调用后 parent 的 size 还是 0，不能直接用 parent[i] 赋值。
        - 在 main 里用 resize，会把 size 真的改成 n，并且把元素初始化出来。这样你才能直接写 parent[i] = i，这也是并查集初始化最常用的做法。
    - 关于答案的遍历
        - 可以使用hash表存储相关信息，并且完成对应的遍历操作
            - `unordered_map<int,vector<int>> rootToIdx;`
            - 在后面的遍历使用count确定是否有讨论过，没有讨论过可以直接push
- 题目解答思路
    - 有关于并查集的问题往往是图论相关的问题。在解答中我们遇到的问题主要是：我们要建成的图像是怎么样的、连通块的含义是什么。
